# Review Engine Evaluation Reports

The reports in this directory are generated from artificial test samples.

These samples are manually constructed for baseline testing. They are not real public recruitment posts, not real contract data, and must not be displayed as real platform data.

Metrics such as Accuracy, Precision, Recall, and F1 only describe performance on the current artificial test set. They do not represent final accuracy on real internet data.

The `confidence` field returned by the review engines is a rule matching confidence hint. It is not Accuracy and must not be presented as a verified real-world accuracy rate.
