# 智法明行项目开发规则

## 一、真实数据要求

网站公开展示的数据不得伪造。

每条外部数据尽可能保存：

- 数据来源名称
- 原始页面 URL
- 原始发布时间
- 数据采集时间
- 数据更新时间
- 数据审核状态

无法确认来源的数据不得进入正式展示页面。

网站统计数字必须由数据库实时计算，不得为了展示效果随意编造。

---

## 二、岗位 JD 审查要求

岗位审查不得只依赖简单关键词判断。

系统采用：

规则匹配
+
上下文分析
+
文本结构化提取
+
语义风险识别
+
置信度计算

系统必须返回：

- 综合风险等级
- 风险评分
- 风险类别
- 对应 JD 原文
- 判断原因
- 数据或规则依据
- 风险提示
- 核实建议
- 模型置信度

---

## 三、准确率评估要求

建立人工标注测试集。

使用以下指标评价：

- Accuracy
- Precision
- Recall
- F1-score

未经测试，不得直接宣传固定准确率。

---

## 四、产品边界

平台提供岗位风险辅助识别、合同风险提示和权益知识服务。

系统结果不替代律师提供的正式法律意见。
