# 智法明行

大学生实习权益智能助手。

## 核心功能

1. 公开实习岗位数据展示
2. 岗位 JD 智能风险审查
3. 实习合同风险辅助审核
4. 大学生实习权益知识库
5. 维权流程与官方渠道指引
6. 数据管理与风险规则后台
7. 微信小程序轻量服务端

## 技术架构

- Web：Vue 3
- Server：Node.js + Express
- Database：MySQL 8.0
- Data Collection：Python
- NLP：Python 文本处理与语义分析
- Mini Program：微信小程序

## 项目原则

- 数据真实
- 来源可追溯
- 不伪造产品数据
- JD 审查结果提供原文证据
- 审查效果使用测试集进行评价
